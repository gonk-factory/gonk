**Goal:** Ship `chart/gonk` — a Helm chart that deploys `gonk-intake` and
`gonk-meter`, mounts their externally-provisioned secrets as files, renders the
operator config they consume, wires Prometheus/Grafana, locks the network down,
switches the ledger between Dolt and CNPG Postgres, and makes every
bring-your-own seam (GitLab, LiteLLM, Postgres, Gas City) explicit — with a test
suite that runs **without a cluster**.

**Architecture:** gonk is a Gas City *pack plus glue* (spec §1). The chart deploys
**gonk's two services** and the **ledger** they need; it does **not** reimplement
Gas City, does not deploy the controller, and does not deploy LiteLLM. Everything
else is a seam. Fail-closed is the design rule: a misconfiguration that could let
work run unmetered, unbudgeted, or unverified must be **impossible** (schema),
**loud at render time** (`fail`), or **loud at startup** (the binary refuses to
boot) — never silently permissive.

**Tech Stack:** Helm 3 (>= 3.14; `helm v3.19.0` is what the owner has),
`values.schema.json` (JSON Schema draft 2020-12, enforced by Helm itself),
`kubeconform` v0.6.7, and **Go tests that shell out to `helm template`** (see
"Why not helm unittest", below). No cluster, anywhere in this plan.

**Spec:** `docs/superpowers/specs/2026-07-12-gonk-stack-design.md` — §4.1
(components), §5.1 (credential modes), §7.4 (**BYO seams — the heart of this
plan**), §8 (observability, three dashboards), §9 (security posture), §10.3
(component tests), §11 (validation milestones), §12 (risks).

**Depends on:** `docs/superpowers/plans/2026-07-13-plan-02-gitlab-intake.md`,
`docs/superpowers/plans/2026-07-13-plan-03-gonk-meter.md`, ADR-002.

## The secret provisioning contract (hard requirement)

**No secret value appears in `values.yaml`. No secret is committed. No secret is
an env var.** The path is: **Vault/1Password → ExternalSecret (or vault-injector)
→ k8s Secret → projected file mount → the binary reads the file** [P02 §Task 10,
P03 §Decision 12]. Every credential has **two rotation slots** so a rotation is
not an outage.

The chart consumes Secrets it did not create. This is the exact contract the
operator must satisfy — the chart mounts these paths and passes them as
`*_FILE` env vars. **A Secret or key that is missing makes the pod fail to
start** (projected volumes are `optional: false`), which is the loud failure we
want, not a silent one.

| Secret (default name) | Key | Mounted at | Env var | Consumer |
|---|---|---|---|---|
| `gonk-gitlab` | `token` | `/etc/gonk/secrets/gitlab/token` | `GONK_GITLAB_TOKEN_FILE` | intake |
| `gonk-gitlab` | `admin-token` *(only when `gitlab.mode=split-credential`)* | `/etc/gonk/secrets/gitlab/admin-token` | `GONK_GITLAB_ADMIN_TOKEN_FILE` | intake |
| `gonk-webhook` | `token` | `/etc/gonk/secrets/webhook/token` | `GONK_WEBHOOK_SECRET_FILE` | intake |
| `gonk-webhook` | `token-previous` *(rotation slot 2, opt-in)* | `/etc/gonk/secrets/webhook/token-previous` | `GONK_WEBHOOK_SECRET_PREVIOUS_FILE` | intake |
| `gonk-meter-api` | `token` | `/etc/gonk/secrets/meter-api/token` | `GONK_METER_TOKEN_FILE` | **intake and meter** |
| `gonk-meter-api` | `token-previous` *(slot 2, opt-in)* | `/etc/gonk/secrets/meter-api/token-previous` | `GONK_METER_TOKEN_PREVIOUS_FILE` | **meter only** (it is the verifier; intake presents slot 1) |
| `gonk-litellm` | `admin-key` | `/etc/gonk/secrets/litellm/admin-key` | `LITELLM_ADMIN_KEY_FILE` | meter |
| `gonk-litellm` | `admin-key-previous` *(slot 2, opt-in)* | `/etc/gonk/secrets/litellm/admin-key-previous` | `LITELLM_ADMIN_KEY_PREVIOUS_FILE` | meter |
| `gonk-ledger` | `dsn` | `/etc/gonk/secrets/ledger/dsn` | `GONK_METER_STORE_DSN_FILE` **(new — see Task 0)** | meter |

Mount rules, applied identically everywhere (Task 3 and Task 5 both use the
`gonk.secretVolumes` / `gonk.secretMounts` helpers from Task 1):

- `projected` volumes, `defaultMode: 0400`, container mount `readOnly: true`.
- **Never** `envFrom`, **never** `valueFrom.secretKeyRef`. If you find yourself
  typing either, stop: that puts the material in `/proc/<pid>/environ` and every
  child process.
- Rotation slot 2 is **opt-in per credential** (`secrets.rotation.*`), because a
  projected volume with a `key` that does not exist in the Secret makes the pod
  fail to start — and slot 2 usually does not exist.

> **Incoherence found (report, do not paper over):** [P02 §Task 10] prose says
> "two rotation slots for every credential (the GitLab bot token, the webhook
> secret, the meter bearer token)", but the `Config` struct it ships has **no
> `GONK_GITLAB_TOKEN_PREVIOUS_FILE`** — the GitLab PAT has one slot only. The
> chart therefore mounts one slot for the GitLab token. That is correct *for the
> code as planned*, and it means **rotating the GitLab PAT is a brief outage**
> (a restart with the new value). Recorded in Task 0.

## Fail-closed guards (the complete enumeration)

Three layers. **A. Schema** (`values.schema.json`, enforced by Helm before any
template runs — a violation is impossible, not just loud). **B. Render-time
`fail`** (for cross-field invariants JSON Schema cannot express). **C. Startup**
(the binary refuses to boot; the chart's only job is to be unable to prevent it).

| # | Unsafe state | Guard | Layer |
|---|---|---|---|
| G1 | **Empty instance ladder** → any project may name any rung, bounded only by budget (PLAN.md carry-forward, ADR-002) | `operatorConfig.instance.ladder` `minItems: 1` | **A** + C (`opercfg.Load` refuses to start) |
| G2 | A rung named in a ladder is **not in the catalog** → meter cannot price it | `fail` listing the unknown rungs | **B** |
| G3 | **Local rung with no synthetic price** → LiteLLM's USD door never closes on tokens (P03 Decision 9) | `fail` | **B** + C |
| G4 | **Cloud rung priced at $0** → free money past the cost gate | `fail` (schema: `est_cost_usd` `exclusiveMinimum: 0` when `kind: cloud`) | **A/B** + C |
| G5 | **Onboarding default rung not in the instance ladder** → *every newly-onboarded project resolves to `disabled`* (OD-B in P02/P03) | `fail` | **B** |
| G6 | **Meter scaled past 1 replica** → its in-process per-project lock stops serializing; two replicas can each grant the last of a budget (P03 AD-10) | `fail` unless `meter.unsafeAllowMultipleReplicas: true`, and the message says exactly what breaks | **B** |
| G7 | **No webhook secret** → unverified webhooks | There is **no value that disables verification.** `secrets.webhook.existingSecret` is `required` + `minLength: 1`; intake refuses to start on an empty secret file | **A** + C |
| G8 | **Meter unreachable / not deployed, intake dispatching anyway** | `fail` if `intake.enabled` and neither `meter.enabled` nor `intake.meterURL` is set. (The deeper guard is in code: intake dispatches **nothing** for a project it has not got a `200 / state: active` for [P02 §"Failure semantics"], and its `/readyz` is false while meter's `/healthz` is down.) | **B** + C |
| G9 | **Orders silently going nowhere** (`LogDispatcher`) | `fail` if `gascity.dispatch: http` and `gascity.supervisorURL` is empty; `dispatch: log` must be typed **deliberately** | **B** |
| G10 | **NetworkPolicy that selects no pods** — an agent-pod egress policy with a wrong selector is a policy that *renders, validates, and blocks nothing* | `fail` if `networkPolicy.enabled` and `networkPolicy.agentPodSelector` is `{}`. **This one cannot be fully closed without a cluster — Plan 06 must prove the egress is actually denied.** | **B** + **Plan 06** |
| G11 | **`latest` / empty image tag** → an unreproducible deploy, and a silent rollback of the budget enforcer | schema `pattern` on `*.image.tag` rejecting empty and `latest` | **A** |
| G12 | **Ingress enabled with no host or class** | `fail` | **B** |
| G13 | **Ingress exposing the private listener** (metrics/health/**`/admin/reconcile`**) | The Ingress backend is hard-wired to the public Service and its single port; a test asserts port `9090` and the private Service name appear in **no** Ingress | **B** + test |
| G14 | **A secret in `values.yaml`** | A test greps the rendered output and `values.yaml` for `glpat-`, `sk-`, `-----BEGIN`, and asserts no `Secret` object is rendered by the chart **at all** | test |
| G15 | **`ledger.backend: memory`** (meter's test-only store — loses reservations on restart, fail-open on headroom) | Not in the enum. It cannot be set. | **A** |

## Why not `helm unittest`

Spec §10.3 says "helm lint + helm unittest + kubeconform". We keep `helm lint`
and `kubeconform` and **replace `helm unittest` with Go tests that shell out to
`helm template`** (`internal/charttest`, build tag `chart`). Reasons, in order:

1. **The fail-closed guards are the most important thing in this chart, and they
   are assertions that `helm template` *fails* with a specific message.**
   `helm unittest`'s `failedTemplate` can do this, but a Go test does it with the
   full `errors.Is`/substring machinery and no plugin.
2. **No plugin to install.** The owner's runners were offline for all of Plan 01
   (PLAN.md). `helm plugin install` needs the network; `go test` does not.
3. It joins the **existing repo gate** (`go test ./... -race -count=1`).

The chart tests are behind `//go:build chart` and need `helm` and `kubeconform`
on `PATH`. Both are already installed on the owner's box (`helm v3.19.0`,
`kubeconform v0.6.7`). **The gate is: `go test -tags chart ./internal/charttest/... -count=1`.**

## Owner decisions needed

**OD-1 — Image registry and tags.** The chart needs `image.registry` and a tag per
image. Plan 04 builds the images and has not run. *Assumed nothing:* `image.tag`
has **no default** and the schema **rejects empty and `latest`** (G11), so
`helm install` without `--set` fails immediately with a schema error. That is
deliberate: guessing a registry would produce a chart that renders and cannot pull.

**OD-2 — Ingress + TLS.** Which ingress class, which host, who issues the cert,
and does GitLab trust it (`GONK_WEBHOOK_SSL_VERIFY`, default true, will reject a
self-signed ingress cert)? *Assumed default:* `ingress.enabled: false` — the chart
does not expose anything until you say so. `intake.webhookPublicURL` is **required
regardless**, because intake writes it into every GitLab hook it provisions; if
you front the webhook with a Gateway/Traefik `IngressRoute` outside this chart,
set the URL and leave `ingress.enabled: false`.
*Blast radius if wrong:* GitLab cannot reach the webhook → reconciliation (every
10 min) still works, so gonk degrades to slow, not broken (spec §5.2).

**OD-3 — Does the chart bundle LiteLLM?** Spec §4.1 lists "LiteLLM proxy
Deployment (+ Postgres)" among the chart's components; spec §7.4 says
`litellm.enabled: false` + `externalUrl` is supported. These pull opposite ways.
*Assumed default: **external / BYO only** in v1* (`litellm.mode: external`,
`externalURL` required). Bundling LiteLLM means a subchart dependency,
`helm dependency build` in CI (network), and owning its Postgres — a large lift
for a component the owner already plans to run. The seam is left open
(`litellm.mode` is an enum with one member; adding `subchart` later is additive).
*Blast radius if wrong:* the operator deploys LiteLLM themselves. The chart still
validates the URL, mounts the admin key, and renders the **synthetic price list**
for them to paste into LiteLLM's model config (Task 2).

**OD-4 — Is Gas City already deployed, and how is gonk's pack registered with
it?** The chart needs the supervisor URL, and the pack (Plan 04) needs to be
imported by the city's root `pack.toml` at a pin — which lives in the **private
`gonk-city` repo** (spec §7.3), not in this chart. *Assumed:* Gas City is
**external**; the chart takes `gascity.supervisorURL` and **does not** attempt to
register the pack. If the intent is for the chart to own the city, that is a
different chart and a different plan.

**OD-5 — What labels does Gas City's k8s session provider put on agent pods?**
Spec §9's central security claim — "agent pods have egress only to GitLab and
LiteLLM, so budgets cannot be bypassed" — is enforced by a NetworkPolicy whose
`podSelector` must match those pods. **We do not know the labels.** Guard G10
refuses to render an empty selector, but a *wrong* selector renders fine and
enforces nothing. **This is the most dangerous unknown in the chart.** Plan 04
must supply the labels; **Plan 06 must prove the egress is actually blocked** by
curling the internet from inside a real session pod.

**OD-6 — GitLab egress CIDR.** A NetworkPolicy egress rule cannot name a DNS host;
it needs an `ipBlock` CIDR (or a `podSelector` if GitLab is in-cluster).
`networkPolicy.gitlab.cidrs` has **no default**. If GitLab is on-cluster, use
`networkPolicy.gitlab.podSelector` + `namespaceSelector` instead.

**OD-7 — The CI tools image.** `chart-lint` can run on `alpine/helm:3.19.0`. The
Go chart tests need an image with **go + helm + kubeconform**. The owner names it
(or we build one in Plan 04's image pipeline). Until then the chart gate is
**local** — which is where Plan 01's gate already lives (PLAN.md).

**OD-8 — Chart publishing.** Spec §7.1 says CI publishes the chart as OCI. Which
registry, which credentials? Not answered; the plan ships a `chart-publish` job
that is `when: manual` and `rules: never` by default, with a TODO.

## Assumed defaults (revisit if wrong)

**AD-1 — Namespace: `gonk`, and the chart does not create it.** Helm/Flux owns
namespace creation. *Blast radius:* `helm install -n gonk --create-namespace`, or
a Flux `HelmRelease` with `targetNamespace`. Nothing in the chart hard-codes it.

**AD-2 — StorageClass: `""` (the cluster default).** Spec §3 says Longhorn, but
naming it hard-codes the homelab into an open-source chart. *Blast radius:* if the
cluster has no default StorageClass, the ledger PVC pends forever and meter never
becomes ready — loud, not silent.

**AD-3 — `ledger.backend: dolt`, `mode: bundled`.** This is Plan 03's Decision 10,
**pending Task 0b**. *Blast radius:* if Task 0b fails, flip to
`ledger.backend: postgres`, `postgres.mode: cnpg` — **which this chart already
supports, fully, on day one.** That is why the switch exists. The Dolt the chart
bundles is the **ledger's**, and is *not* Gas City's bead store (spec §4.1's Dolt);
whether they should share one `dolt sql-server` is an open question and the chart
takes no position (`ledger.dolt.mode: external` lets you point at the bead store's).

**AD-4 — Instance budget defaults to `monthly_cost_usd: 0`.** The chart, out of
the box, **cannot spend a single dollar**: the only rung in the default catalog is
local, and the instance cost ceiling is zero (ceilings only tighten downward, so
no `.gonk.yml` can raise it). Enabling cloud rungs is a **deliberate three-part
edit**: add the rung to `operatorConfig.rungs`, add it to
`operatorConfig.instance.ladder`, and raise `instance.budget.monthly_cost_usd`.
*Blast radius:* someone is surprised that cloud rungs defer. Good.

**AD-5 — `intake.replicaCount: 2`, `meter.replicaCount: 1`.** Intake is stateless
and idempotent (its cache is derived); meter is **not** horizontally safe (G6).

**AD-6 — Monitoring CRs are off by default** (`serviceMonitor.enabled: false`,
etc.) and are gated by **values, not `.Capabilities.APIVersions`**. Capability
gating makes `helm template` render differently from `helm install`, which would
make the golden tests a lie. Turn them on explicitly.

**AD-7 — Grafana dashboard discovery label: `grafana_dashboard: "1"`**
(kube-prometheus-stack's sidecar default), overridable.

## What `helm template` CANNOT prove → hand to Plan 06

A chart that renders is not a chart that works. **These are Plan 06's, and they
are not smuggled in here:**

1. **The Secret actually exists and actually mounts.** `helm template` is happy to
   reference `gonk-webhook`; a missing Secret is a `CreateContainerConfigError` at
   runtime. Same for a **wrong key name** — the whole contract table above is
   unverified until a pod starts.
2. **The NetworkPolicy actually blocks.** Rendering a policy proves nothing: the
   CNI must enforce it, and **the agent-pod selector must actually match the pods
   Gas City creates (OD-5)**. Plan 06: exec into a session pod, `curl` a
   non-allow-listed host, require a timeout. If this test does not exist, spec §9's
   "budgets cannot be bypassed" is an unverified claim.
3. **The probes actually pass.** Intake's `/readyz` requires the bot identity to
   resolve, the first reconcile to complete, and **meter's `/healthz` to be OK**
   [P02 §Task 10]; meter's `/readyz` is false until its **first spend sync**
   completes [P03]. Neither can be exercised without GitLab and LiteLLM.
4. **The readiness coupling's blast radius.** Meter down → intake NotReady →
   removed from the Service → the Ingress 502s → **GitLab may auto-disable the
   webhook** after repeated failures [P02 §Plan-06 item 6]. Fail-closed, but the
   recovery path needs a real test.
5. **ServiceMonitor actually scrapes** (label selector must match the Prometheus
   Operator's `serviceMonitorSelector`) and **the Grafana sidecar actually
   discovers** the dashboard ConfigMaps.
6. **The RBAC actually permits** meter's KeySink to write per-project Secrets
   (Task 4 tests against a fake clientset; a fake clientset does not enforce RBAC).
7. **CNPG's `Cluster` actually reconciles** / the Dolt PVC actually binds.
8. **The synthetic price agreement.** The chart renders the same prices into the
   operator config *and* into an advisory LiteLLM model-price ConfigMap — but
   nothing verifies the operator actually pasted them into LiteLLM. **A local rung
   priced at $0 in LiteLLM means the USD virtual-key door never closes on tokens**
   [P03 Decision 9]. Plan 06 must diff LiteLLM's `/model/info` against the catalog.
9. **`helm install` on kind and on the real cluster**, idle = platform services
   only, zero agent pods (spec §11.1).

func helm(t *testing.T, args ...string) (string, error) {
	t.Helper()
	if _, err := exec.LookPath("helm"); err != nil {
		t.Fatalf("helm is not on PATH; the chart gate needs it: %v", err)

	err := cmd.Run()
	if err != nil {
		return stdout.String() + stderr.String(), err

}

func Render(t *testing.T, extra ...string) string {

// Object is one rendered Kubernetes object, parsed just enough to assert on.
type Object struct {
	APIVersion string         `yaml:"apiVersion"`
	Kind       string         `yaml:"kind"`
	Metadata   struct {
		Name        string            `yaml:"name"`
		Labels      map[string]string `yaml:"labels"`
		Annotations map[string]string `yaml:"annotations"`
	} `yaml:"metadata"`
	Raw map[string]any `yaml:"-"`
	Doc string         `yaml:"-"` // the original YAML text
}

func (o Object) Data(t *testing.T) map[string]string {
	t.Helper()
	d, _ := o.Raw["data"].(map[string]any)
	out := map[string]string{}
	for k, v := range d {
		s, _ := v.(string)
		out[k] = s
	}
	return out
}

// Objects splits a multi-document render into parsed objects, dropping empties.
func Objects(t *testing.T, out string) []Object {
	t.Helper()
	var objs []Object
	dec := yaml.NewDecoder(strings.NewReader(out))
	for {
		var raw map[string]any
		err := dec.Decode(&raw)
		if err != nil {
			break
		}
		if len(raw) == 0 {
			continue
		}
		b, _ := yaml.Marshal(raw)
		var o Object
		if err := yaml.Unmarshal(b, &o); err != nil {
			t.Fatalf("parse rendered object: %v\n%s", err, string(b))
		}
		o.Raw, o.Doc = raw, string(b)
		objs = append(objs, o)
	}
	return objs
}

// MustObject finds exactly one object by kind+name, or fails with the list of
// what WAS rendered (which is what you actually want when it is missing).
func MustObject(t *testing.T, out, kind, name string) Object {
	t.Helper()
	var have []string
	for _, o := range Objects(t, out) {
		if o.Kind == kind && o.Metadata.Name == name {
			return o
		}
		have = append(have, o.Kind+"/"+o.Metadata.Name)
	}
	t.Fatalf("no %s/%s in the render; got:\n  %s", kind, name, strings.Join(have, "\n  "))
	return Object{}
}

// NoObject asserts a kind+name is absent.
func NoObject(t *testing.T, out, kind, name string) {
	t.Helper()
	for _, o := range Objects(t, out) {
		if o.Kind == kind && o.Metadata.Name == name {
			t.Fatalf("%s/%s was rendered and must not be", kind, name)
		}
	}
}

// Kubeconform validates a render against the Kubernetes API schemas. CRDs
// (ServiceMonitor, PrometheusRule, CNPG Cluster) have no upstream schema, so
// they are validated against vendored schemas in chart/gonk/tests/crd-schemas/
// -- NOT with -ignore-missing-schemas, which would silently skip them.
func Kubeconform(t *testing.T, render string, crdSchemaDir string) {
	t.Helper()
	if _, err := exec.LookPath("kubeconform"); err != nil {
		t.Fatalf("kubeconform is not on PATH; the chart gate needs it: %v", err)
	}
	f := filepath.Join(t.TempDir(), "render.yaml")
	if err := os.WriteFile(f, []byte(render), 0o600); err != nil {
		t.Fatal(err)
	}
	args := []string{"-strict", "-summary"}
	if crdSchemaDir != "" {
		args = append(args, "-schema-location", "default",
			"-schema-location", filepath.Join(crdSchemaDir, "{{.ResourceKind}}_{{.ResourceAPIVersion}}.json"))
	}
	cmd := exec.Command("kubeconform", append(args, f)...)
	var b bytes.Buffer
	cmd.Stdout, cmd.Stderr = &b, &b
	if err := cmd.Run(); err != nil {
		t.Fatalf("kubeconform failed: %v\n%s", err, b.String())
	}
}

// mustFail renders and requires the error message to contain `want`. A guard
// whose message does not say what is wrong is a guard nobody can act on.
func mustFail(t *testing.T, want string, extra ...string) {
	t.Helper()
	out, err := RenderErr(t, append(Minimum(), extra...)...)
	if err == nil {
		t.Fatalf("render SUCCEEDED and must not have (expected %q)", want)
	}
	if !strings.Contains(out, want) {
		t.Fatalf("guard fired with the wrong message.\nwant substring: %q\ngot:\n%s", want, out)
	}
}

```go
package keysink

import (
	"context"
	"fmt"

	corev1 "k8s.io/api/core/v1"
	apierrors "k8s.io/apimachinery/pkg/api/errors"
	metav1 "k8s.io/apimachinery/pkg/apis/meta/v1"
	"k8s.io/client-go/kubernetes"

	"gitlab.orac.local/agentic/gonk-project/internal/meter/store"
)

// SecretKey is the key inside the per-project Secret. Agent pods project it into
// their environment as the LiteLLM virtual key; the pack (Plan 04) references it
// through the KeyRef meter returns. Changing this string breaks the agent image.
const SecretKey = "LITELLM_API_KEY"

// K8s writes each project's LiteLLM virtual key into its own Kubernetes Secret.
//
// This is the delivery mechanism for the whole attribution chain: an agent pod
// gets a key that is scoped to ONE project, with ONE budget, so LiteLLM's hard
// refusal lands on the right project. The key material NEVER travels through
// meter's HTTP responses, the event bus, or a log line -- meter hands out only a
// KeyRef, and this is what the ref points at.
//
// One Secret per project (not one Secret with N keys) so that RBAC can, later,
// scope an agent pod to exactly its own key.
type K8s struct {
	cs        kubernetes.Interface
	namespace string
	prefix    string
}

func NewK8s(cs kubernetes.Interface, namespace, prefix string) *K8s {
	return &K8s{cs: cs, namespace: namespace, prefix: prefix}
}

func (k *K8s) name(project string) string { return k.prefix + Slug(project) }

// Put is idempotent: intake re-registers every project on every reconcile pass
// (every 10 minutes), and a rotation must overwrite rather than duplicate.
func (k *K8s) Put(ctx context.Context, project, token string) (store.KeyRef, error) {
	name := k.name(project)
	ref := store.KeyRef{SecretName: name, SecretKey: SecretKey}
	sec := &corev1.Secret{
		ObjectMeta: metav1.ObjectMeta{
			Name:      name,
			Namespace: k.namespace,
			Labels: map[string]string{
				"app.kubernetes.io/managed-by": "gonk-meter",
				"app.kubernetes.io/part-of":    "gonk",
				"gonk.orac.local/project":      Slug(project),
			},
			Annotations: map[string]string{
				// The slug is lossy; keep the real path for a human, and for
				// meter's own reconcile. It is not a secret.
				"gonk.orac.local/project-path": project,
			},
		},
		Type: corev1.SecretTypeOpaque,
		Data: map[string][]byte{SecretKey: []byte(token)},
	}

	_, err := k.cs.CoreV1().Secrets(k.namespace).Create(ctx, sec, metav1.CreateOptions{})
	if err == nil {
		return ref, nil
	}
	if !apierrors.IsAlreadyExists(err) {
		// Never wrap the token into an error: errors get logged.
		return store.KeyRef{}, fmt.Errorf("keysink: create secret %s/%s: %w", k.namespace, name, err)
	}
	if _, err := k.cs.CoreV1().Secrets(k.namespace).Update(ctx, sec, metav1.UpdateOptions{}); err != nil {
		return store.KeyRef{}, fmt.Errorf("keysink: update secret %s/%s: %w", k.namespace, name, err)
	}
	return ref, nil
}

// Delete removes a project's key. De-onboarding must leave no live credential
// behind. Deleting an absent key is a no-op.
func (k *K8s) Delete(ctx context.Context, project string) error {
	err := k.cs.CoreV1().Secrets(k.namespace).Delete(ctx, k.name(project), metav1.DeleteOptions{})
	if err != nil && !apierrors.IsNotFound(err) {
		return fmt.Errorf("keysink: delete secret %s/%s: %w", k.namespace, k.name(project), err)
	}
	return nil
}
```

```go
//go:build chart

package charttest

import (
	"flag"
	"os"
	"path/filepath"
	"testing"
)

var update = flag.Bool("update", false, "rewrite the golden manifests")

// Golden manifests: the whole rendered output of each profile, byte for byte.
// This is the drift gate. A change to a helper that quietly moves a volumeMount,
// or a values default that quietly opens a port, shows up here as a diff a human
// has to look at and approve. Regenerate deliberately:
//
//	go test -tags chart ./internal/charttest/ -run Golden -update
func TestGoldenManifests(t *testing.T) {
	for _, profile := range []string{"values-default", "values-byo-everything", "values-cnpg", "values-full-monitoring"} {
		t.Run(profile, func(t *testing.T) {
			got := Render(t, "--values", filepath.Join(ChartDir(), "ci", profile+".yaml"))
			golden := filepath.Join("testdata", "golden", profile+".yaml")
			if *update {
				if err := os.WriteFile(golden, []byte(got), 0o644); err != nil {
					t.Fatal(err)
				}
				return
			}
			want, err := os.ReadFile(golden)
			if err != nil {
				t.Fatalf("no golden manifest (%v). Run with -update, then READ THE DIFF.", err)
			}
			if got != string(want) {
				t.Errorf("%s drifted from its golden manifest.\n"+
					"Run `go test -tags chart ./internal/charttest/ -run Golden -update` and READ the diff:\n"+
					"a moved volumeMount or an opened port looks exactly like a formatting change.", profile)
			}
		})
	}
}

// Every profile must lint and validate, not merely render.
func TestEveryProfileLintsAndValidates(t *testing.T) {
	crds := filepath.Join(ChartDir(), "tests", "crd-schemas")
	for _, profile := range []string{"values-default", "values-byo-everything", "values-cnpg", "values-full-monitoring"} {
		t.Run(profile, func(t *testing.T) {
			vals := []string{"--values", filepath.Join(ChartDir(), "ci", profile+".yaml")}
			Lint(t, vals...)
			Kubeconform(t, Render(t, vals...), crds)
		})
	}
}
```
